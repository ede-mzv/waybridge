# Changelog

## 1.0.0 — Waybridge rebrand

- Nombre visible, Fabric mod ID, paquete Java, clase principal y nombre del JAR renombrados a Waybridge.
- Migración automática de `config/servercito-teleport.json` a `config/waybridge.json` cuando no existe el nuevo archivo.
- Se conservan `/stp`, `/stwp` y `/stadmin`, sus permisos por UUID, cooldown y lógica de destino seguro.
- Compatibilidad de comandos con Xaero's Minimap / World Map y coexistencia con FTB Essentials.
- La función `/stwpdim` aún **no existe** en esta versión.
